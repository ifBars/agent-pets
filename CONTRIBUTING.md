# Contributing

Agent Pets is early. The contribution bar is intentionally practical:

- Keep the app local-first unless a feature explicitly needs network access.
- Do not add pet package features that execute community code.
- Add provider adapters behind a small read-only boundary.
- Add tests for provider inference and pet package validation.
- Use Bun for package management and scripts.

Good first contribution areas:

- Provider adapters for other coding agents.
- Better Codex state inference as session formats evolve.
- Pet QA and package validation tools.
- Cross-platform packaging.
- Demo pet packs that follow the documented contract.
