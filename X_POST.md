# X Post Template

Bring your Codex pet anywhere.

I built Agent Pets: a tiny desktop companion that turns Codex-compatible pets into a status surface for local coding agents.

It can:
- live on your desktop without an agent
- monitor Codex and OpenCode sessions
- show when work is running or ready for review
- use custom AI-made pets

Install:
```bash
bunx @ifbars/agent-pets
```

OpenCode plugin:
```bash
opencode plugin opencode-agent-pets --global
```

Repo: https://github.com/ifBars/agent-pets
